# Flavoriz Recipe Portal - Automation Guide 🚀

You no longer need to open a terminal and run `node server.js` manually every time you want to use the website!

---

### Option 1: Automatic Windows Startup (Recommended - Set & Forget)
The backend server runs silently in the background whenever your computer turns on. You will **never** have to think about the backend again.

- **To Enable:** Double-click [`install-autostart.bat`](file:///D:/Flavoriz-Recipe-Portal/install-autostart.bat).
- **To Disable:** Double-click [`uninstall-autostart.bat`](file:///D:/Flavoriz-Recipe-Portal/uninstall-autostart.bat).

---

### Option 2: 1-Click Launch (Desktop Shortcut)
Launch the backend and open the website in your browser in one click.

- Double-click [`Start-Flavoriz.bat`](file:///D:/Flavoriz-Recipe-Portal/Start-Flavoriz.bat) or the **Flavoriz Recipe Portal** icon on your Desktop.
- Need to recreate the desktop icon? Double-click [`create-desktop-shortcut.bat`](file:///D:/Flavoriz-Recipe-Portal/create-desktop-shortcut.bat).

---

### Option 3: Stop the Server Anytime
- Double-click [`Stop-Flavoriz.bat`](file:///D:/Flavoriz-Recipe-Portal/Stop-Flavoriz.bat) to stop any running Flavoriz backend instance on port 5000.

---

### Unified Full-Stack Access:
- The website is served at **http://localhost:5000/** (both frontend and backend API run together seamlessly).
- VS Code Live Server (`http://127.0.0.1:5500`) is still 100% supported if you are editing UI code.
